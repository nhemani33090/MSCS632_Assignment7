
# 📊 Statistics Calculator – Multi-Paradigm Assignment

This project implements a statistics calculator (mean, median, mode) in three different programming paradigms:

- **C** (Procedural)
- **OCaml** (Functional)
- **Python** (Object-Oriented)

## 📁 Folder Structure

```
├── C/
│   └── stats.c
├── OCaml/
│   └── stats.ml
├── Python/
│   └── stats.py
├── report/
│   └── statistics_comparison_report.docx
```

## ▶️ How to Run Each Version

### 🟦 C (Procedural)
```bash
cd C
gcc stats.c -o stats
./stats
```

### 🟣 OCaml (Functional)
```bash
cd OCaml
# Option A: Compile and run
ocamlc -o stats stats.ml
./stats

# Option B: Run directly without compiling
ocaml stats.ml
```

### 🐍 Python (Object-Oriented)
```bash
cd Python
python3 stats.py
```
